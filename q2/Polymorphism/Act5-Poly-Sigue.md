1. What do all the methods (move(), special_move(), use()) in the previous activities have in common?

All the methods have the same purpose of performing an action, but their behavior depends on the object calling them. They allow different classes to use the same method name while producing different results.

2. How does this activity show polymorphism in a gaming context?

This activity demonstrates polymorphism because different game characters and items can use the same method name but perform different actions. For example, each character has a different special move, while each potion provides a different effect.

3. Can you think of other examples where the same action behaves differently depending on the character or item?

Yes. A defend() method can behave differently depending on the character. A Warrior can block attacks using a shield, a Mage can create a magic barrier, and an Archer can dodge attacks. Similarly, an equip() method can produce different effects depending on the item being equipped.
